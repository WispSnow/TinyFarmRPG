# 物品栏菜单 — 布局线框图 (Stardew Valley 风格)

> Phase 1 产出物。基于 640×360dp 逻辑分辨率、VonwaonBitmap 16px 像素字体、
> 现有 Tokyo Night 配色方案设计。物品以图标网格展示。

## 设计参考

- **Stardew Valley** — 图标网格背包、顶部标签页、底部角色信息、悬浮 Tooltip
- 像素风格、ninepatch 边框

## 素材约定

- 物品/装备/标签页图标统一 **16×16dp**
- 角色头像 **64×64dp**

---

菜单打开时覆盖全屏，游戏世界在背后可见（半透明遮罩）。
中央大面板包含：标签页 → 背包网格 → 角色信息区。

## 各区域详细设计

### 0. Menu Panel（主面板）

- 尺寸: **440 × 310dp**
- 位置: 居中 `left: 100dp; top: 25dp`
- 背景: ninepatch 面板（复用 `inventory-panel-bg` 或新素材）
- 内边距: `padding: 10dp`
- 内容区: **420 × 290dp**

### 1. Tabs（标签页图标行）

```
  ┌──────────────────────────────────────────────────────────┐
  │ h=20dp                                                    │
  │                                                            │
  │  [📦]  [⚔]  [📋]  [🗺]  [⚙]                             │
  │   ↑                                                        │
  │  16×16dp per icon, gap 6dp                                │
  │  selected: highlight border / glow                        │
  └──────────────────────────────────────────────────────────┘
```

- 位置: 面板内 `top: 0`
- 每个标签: **16×16dp** 图标 + 2dp padding = 20×20dp 点击区域，间距 6dp
- 选中标签: 底部高亮条 2dp (#7aa2f7) 或 box-shadow
- 未选中: 半透明 (opacity 0.5)

| 标签 | 内容 | 状态 |
|------|------|------|
| 📦 Inventory | 物品栏（本页） | 初期实现 |
| ⚔ Equipment | 装备管理 | 未来 |
| 📋 Quests | 任务日志 | 未来 |
| 🗺 Map | 地图 | 未来 |
| ⚙ Options | 设置 | 未来 |

- 键盘: Q / E（或 LB / RB）切换标签页

### 2. Backpack（背包网格）

```
  ┌─────────────────────────────────────────────┐  ┌────┐
  │ 10 × 4 grid                                 │  │ 🗑 │
  │ slot 20×20dp, gap 2dp                       │  │16dp│
  │                                              │  └────┘
  │ [🔨][🪓][⛏][💧][🌾][ ][ ][ ][ ][ ]       │
  │ [🍓][🥔][🪵][🪨][ ][ ][ ][ ][ ][ ]       │
  │ [ ][ ][ ][ ][ ][ ][ ][ ][ ][ ]             │
  │ [ ][ ][ ][ ][ ][ ][ ][ ][ ][ ]             │
  │                                              │
  │ w=218dp, h=86dp                              │
  └─────────────────────────────────────────────┘
```

- 位置: 面板内 `top: 28dp`（tabs 20dp + gap 8dp）
- 网格: **10 × 4** = **40 槽位**（与现有容量一致）
- 每个 slot: **20×20dp**，gap **2dp**
- 总尺寸: (20×10 + 2×9) × (20×4 + 2×3) = **218 × 86dp**
- 右上角: 垃圾桶图标 16×16dp（选中物品 + 按键丢弃）

**单个 Slot 内部结构:**

```
  ┌──────────────┐
  │ 20×20dp      │
  │ ┌──────────┐ │
  │ │ 16×16    │ │  ← icon decorator, 居中 (2dp padding)
  │ │  icon    │ │
  │ └──────────┘ │
  │         ×12──│  ← 数量文字, 右下角, 仅 >1 显示
  └──────────────┘
  背景: ninepatch slot-bg
  选中: slot-selected / box-shadow 高亮
```

- 空槽: 仅显示 slot 背景
- 有物品: 居中 16×16 图标 + 右下角数量（12dp 字体）
- 选中状态: 高亮边框 (#7aa2f7)
- 键盘导航: ↑↓←→ 在 10×4 网格中移动

### 3. Character Info（角色信息区）

```
  ┌────────┐                  ┌──────┬──────┐
  │        │                  │ hat  │ neck │
  │ avatar │  PlayerName      │16×16 │16×16 │    Gold: 1,234g
  │ 64×64  │  Lv.1 Farmer    ├──────┼──────┤    Farm: TinyFarm
  │        │                  │shirt │glove │
  │        │                  ├──────┼──────┤
  └────────┘                  │pants │ring1 │
                              ├──────┼──────┤
                              │boots │ring2 │
                              └──────┴──────┘
  ←─ 72dp ─→←── 120dp ──→    ←── 44dp ──→     ←── 140dp ──→
```

- 位置: 面板内 `top: 122dp`（backpack 86dp + top 28dp + gap 8dp）
- 高度: **80dp**

**子区域:**

| 子区域 | 位置 (面板内相对) | 尺寸 | 内容 |
|--------|-------------------|------|------|
| Avatar | left: 0 | 64×64dp | 角色像素头像 |
| Name + Title | left: 72dp | 120×40dp | 名称 (16dp, #fff) + 等级职业 (16dp, #a9b1d6) |
| Equipment | left: 200dp | 2×4 grid | 8 个装备槽 (20×20dp, gap 2dp) |
| Farm + Gold | left: 290dp | 130×40dp | 金币 (#e0af68) + 农场名 (#a9b1d6) |

**装备槽 2×4 网格:**

```
  col 0    col 1
  ┌──────┬──────┐
  │ hat  │ neck │  row 0   头部 / 项链
  ├──────┼──────┤
  │shirt │glove │  row 1   上衣 / 手套
  ├──────┼──────┤
  │pants │ring1 │  row 2   下装 / 戒指1
  ├──────┼──────┤
  │boots │ring2 │  row 3   鞋子 / 戒指2
  └──────┴──────┘
  slot: 20×20dp, gap: 2dp
  总尺寸: 42 × 86dp
```

| 槽位 | 位置 | 说明 |
|------|------|------|
| Hat | (0,0) | 帽子/头盔 |
| Necklace | (1,0) | 项链 |
| Shirt | (0,1) | 上衣/胸甲 |
| Gloves | (1,1) | 手套 |
| Pants | (0,2) | 裤子/下装 |
| Ring 1 | (1,2) | 戒指 |
| Boots | (0,3) | 鞋子 |
| Ring 2 | (1,3) | 戒指 |

- 每个装备槽: 20×20dp，内含 16×16 图标
- 空槽显示对应部位的剪影/轮廓图标（半透明）
- 初期显示为锁定状态（灰色），后续实装装备系统
- 从背包选中装备 → 子菜单 "Equip" → 自动放入对应槽位

### 4. Tooltip（悬浮提示）

```
  ┌────────────────────────────┐
  │ w=max 160dp, dynamic h     │
  │                            │
  │  Strawberry          ×12   │  ← 名称 (16dp, #fff) + 数量 (#9ece6a)
  │  Crop                      │  ← 分类 (16dp, #a9b1d6)
  │  A sweet red berry.        │  ← 描述 (16dp, #ffffffcc)
  │  Can be eaten or           │
  │  processed into seeds.     │
  └────────────────────────────┘
```

- 浮动定位: 跟随选中 slot 右侧或下方，不遮挡当前选中项
- 背景: ninepatch (`tooltip-panel-bg`)
- 键盘模式: 选中 slot 变化时即显示
- 鼠标模式: hover 时显示
- 空 slot / 锁定装备槽: 不显示 Tooltip

## 交互流程

### 基本导航

```
  打开菜单 (Menu 键 / Esc)
       │
       ▼
  ┌─ Backpack Grid 获得焦点 ──────────────┐
  │  ↑↓←→ 在 10×4 网格中移动              │
  │  从首行按 ↑ → 进入 Tabs               │
  │  从末行按 ↓ → 进入 Equipment slots    │
  │  Enter/Z → 打开操作子菜单             │
  │  Esc/X → 关闭菜单                     │
  │  Q/E → 切换标签页                      │
  └────────────────────────────────────────┘
```

### 物品操作

```
  选中一个有物品的 Slot，按 Enter/Z
       │
       ▼
  ┌─ Action Sub-menu (弹出) ───────┐
  │                                 │
  │  ► Use          (消耗品)        │
  │    Equip        (装备类)        │
  │    Discard                      │
  │    Cancel                       │
  │                                 │
  │  ↑↓ 选择，Enter 确认            │
  │  Esc 取消                       │
  └─────────────────────────────────┘
```

### 装备槽导航

```
  从 Backpack 末行按 ↓
       │
       ▼
  ┌─ Equipment Grid (2×4) ─────────┐
  │  ↑↓←→ 在装备槽间移动           │
  │  ↑ 从首行回到 Backpack          │
  │  Enter/Z → Unequip (卸下装备)   │
  │  Esc/X → 关闭菜单              │
  └─────────────────────────────────┘
```

## 与现有资源的关系

**复用:**
- `slot-normal` / `slot-selected` ninepatch (ui-slots spritesheet, 16×16 原始)
- 所有 `ui-items-*` spritesheet 物品图标 (16×16)
- `tooltip-panel-bg` ninepatch
- `.panel-dark` 风格配色
- VonwaonBitmap 16px 字体

**需要新素材 (用户后续提供):**
- 菜单主面板 ninepatch 背景（或复用 inventory-panel-bg 拉伸）
- 标签页图标 (5 个 16×16: 背包/装备/任务/地图/设置)
- 垃圾桶图标 (16×16)
- 角色头像 (64×64)
- 装备槽部位剪影图标 (8 个 16×16: hat/neck/shirt/glove/pants/ring/boots/ring)
- 装备槽背景 ninepatch (区别于普通 slot，可选)

**不再使用:**
- Hotbar 相关 UI（hotbar.rml/rcss、HotbarUI、HotbarComponent、HotbarSystem）
- 物品栏拖拽代理 (drag proxy)
- 物品栏翻页按钮
- 拖拽手柄 (drag handle)
- 浮动小窗口定位方式
