我已经梳理清楚了当前战斗场景的实现状态。结合截图与现有代码（Side View 布局、HUD、菜单闭环、AI、奖励结算都已落地），下面分模块给出对标 RPG Maker MV/MZ 的完善建议。

## 📊 当前状态概览

**已实现**：Side View 布局、回合驱动、技能/物品/防御/逃跑菜单、敌方 AI、伤害公式（Lua）、状态系统骨架、奖励写回、Quest 联动。

**主要差距**（对照 RPG Maker MV/MZ）：表现层反馈薄弱、战场视觉单调、状态/buff UI 缺失、无战斗日志、无攻击动作演出、行动顺序不可见。

## 🎨 一、视觉与战场表现（短期收益最大）

### 1.1 战斗背景图 （已完成✅，计划文档为`./2026-05-06-battle-background-plan.md`）

当前 `BattleScene::render()` 只画纯色底。建议：
- 在 `BattleScene` 渲染层最底层贴上背景图（按地形/事件指定不同 bg）
- `EnterBattleCommand` 增加 `battlebackground_id` 字段，`RpgCatalog::TroopData` 也可指定
- 对应 RPG Maker 的 `Battleback1`（地面）+ `Battleback2`（远景）双层结构

### 1.2 攻击/受击演出（最影响"战斗手感"）（已完成✅，计划文档为`./2026-05-07-battle-action-hit-animation-plan.md`）

当前只有 idle 动画 + 0.2s 占位计时。推荐分阶段补：
- **行动者位移**：玩家攻击时向目标 hop 一格，命中后弹回（RPG Maker 的 `stepForward`）
- **受击闪烁/抖动**：被击中单位红色 flash + 横向 shake
- **倒下**：HP 归零时角度旋转 90° + 透明度淡出（RPG Maker 风格）
- **施法吟唱**：技能前 actor 略微上下浮动 + Effekseer 吟唱粒子

可以新建 `BattleAnimationDirector`，把 `BattleActionResult` 转成时间轴 tween 序列；`AnimatingResult` 阶段不再是固定 0.2s，而是等 director 报告完成。

### 1.3 伤害数字飘字（DamagePopup）（已完成✅，计划文档为`./2026-05-07-battle-damage-popup-plan.md`）

RPG Maker 标志性的飘字：
- 红字：HP 伤害
- 绿字：HP 恢复
- 蓝字：MP 消耗/恢复
- 灰字 "Miss"，黄字带闪 "Critical!"

实现：在 `BattleScene` 战场层维护一个 popup vector，每个携带 text/color/start_time/world_pos，`update()` 里 lerp Y 上飘 + alpha 衰减。

### 1.4 敌方 HP 条 （已完成✅，计划文档为`./2026-05-07-battle-enemy-hp-bar-plan.md`）

当前 enemy 只有地面阴影，没有可见血条。建议在敌方精灵上方画一条 mini HP bar（首次受击时才显示，3s 后自动隐藏，或始终常驻——可配置）。

## 🧭 二、HUD 与菜单结构

### 2.1 行动顺序条（Turn Order）（已完成✅，计划文档为`./2026-05-08-battle-turn-order-bar-plan.md`）

RPG Maker 默认是回合制（不是 ATB），但即便如此，**显示下一轮内剩余行动序列**对玩家决策非常关键。建议：
- 屏幕顶部一条横向 portrait queue，按速度排序展示本轮接下来谁行动
- 当前行动者高亮，已行动者灰化
- 这能直接落到现有 `TurnCore::order()` 的输出上，纯表现层

### 2.2 状态图标（States）（已完成✅，计划文档为`./2026-05-08-battle-state-icons-plan.md`）

`BattleUnit` 已有 `states_added/removed`，但 HUD 里看不到。建议：
- 党 status 卡 name 右侧加一行小图标条（poison/sleep/silence/buff…）
- 鼠标 hover 显示 tooltip（剩余回合 / 描述）
- 对应 RPG Maker 的 `Game_Battler.states()` 显示

### 2.3 命令面板对齐 RPG Maker 习惯（已完成✅，计划文档为`./2026-05-08-battle-command-panel-rpg-maker-plan.md`）

当前主菜单 6 项垂直/网格混排。RPG Maker 的标准 actor 命令是：
```
Attack / Skill / Guard / Item   (Escape 在队首单独一栏)
```
建议：
- `Escape` 移到"队伍命令"层（PartyCommand）：玩家回合开始时先弹一个 `Fight / Escape`，选 Fight 后才进入逐角色 ActorCommand
- `End Turn` 这个动作 RPG Maker 没有，建议移除或仅留在 debug；真实 JRPG 里玩家不能"跳过"自己的回合
- `Attack` 直接默认 OneEnemy，符合现实现

## 📜 三、战斗日志 / 反馈

### 3.1 滚动战斗日志（已完成✅，计划文档为`./2026-05-08-battle-scroll-log-plan.md`）

此前只有 top-right `result_text` 单行。现已补齐：
- 顶部窄条独立窗口，显示最近 3 行滚动日志
- 每个 action 推入 "Tori attacks Goblin!"、"Goblin takes 24 damage." 等短句
- KO、逃跑、失败、状态变化等关键反馈进入日志
- `result_text` 收束为菜单提示和 `Victory / Defeat / Escaped` 等宏观状态

格式化器已独立为 `BattleLogFormatter`，输入 `BattleActionResult` 输出带 tone 的日志行，便于单元测试和 RmlUi 表现层映射颜色。
