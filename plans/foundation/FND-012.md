## 最终结论
方案 C 已落地，渲染链路升级为：
`Scene -> Lighting -> Emissive -> Bloom -> WorldVfx(FBO) -> Composite -> OverlayVfx(default FB) -> UI -> ImGui`

本任务采用“单 manager + layer/culling mask”实现 Effekseer 双通道路由，避免双 manager 的资源与更新开销。

## 关键实现结果
1. **数据契约升级**
- `engine::vfx::VfxChannel`：`World / Overlay`。
- `VfxPlayRequest`、`VfxRenderContext` 新增 `channel`。
- 默认值保持 `Overlay`，保证历史行为不回退。

2. **新增 WorldVfxPass**
- 新增 `world_vfx_pass.h/.cpp`，独立管理 world-vfx FBO。
- `GLRenderer::clear()` 统一清理 world-vfx 透明缓冲。
- world-vfx 纹理过滤改为 `GL_LINEAR`，减轻放大马赛克感。

3. **Composite 接入 world-vfx 纹理**
- `CompositePass` 新增 `uWorldVfxTex` 采样输入。
- 当前采用 world 增量叠加：`clamp(base + worldVfx.rgb, 0, 1)`。

4. **GLRenderer 双通道与统计拆分**
- `PassType` 拆分为 `WorldVfx` / `OverlayVfx`。
- world/overlay 分别构造 `VfxRenderContext` 并独立统计。
- `setVfxBackend()` 同时委托 world/overlay 两个 pass。

5. **Effekseer 双通道路由（单 manager）**
- 播放时按 `channel` 调用 `SetLayer(handle, layer)`。
- 渲染时按 `DrawParameter::CameraCullingMask` 过滤 layer。
- `last_instance_count` 按当前渲染通道统计。

6. **调试与调用链同步**
- `VfxDebugPanel` 增加 `Spawn Channel`。
- `GLRendererDebugPanel` 增加 `WorldVfxPass` / `OverlayVfxPass` 统计与 world-vfx 预览。
- `PlayVfxCommand` 增加 `channel` 字段并由 `VfxBridgeSystem` 透传。

7. **headless 修复**
- `createHeadless()` 也创建 world-vfx pass（headless 轻量实例）。
- 避免 headless 路径下 world pass 缺失导致行为不一致。

## 审阅意见处理结论
### 第一轮（方案审阅）
- 采纳：单 manager + layer 路由方向。
- 采纳：明确 world/overlay 职责边界与 PassType 拆分。
- 采纳：默认调用保持 overlay 行为，world 走显式通道。

### 第二轮（代码审阅）
- 采纳：修复 headless world-vfx pass 缺失。
- 采纳：`setVfxBackend()` 恢复为直接委托，不做冗余防御。
- 采纳：补回 `setVfxBackend` 双 pass 委托测试。
- 采纳：`PlayVfxCommand` 增加 `channel` 并透传。
- 采纳：合成阶段增加 `clamp`，降低过曝风险。
- 采纳（折中）：world 通道混合先保持加色增量语义，并在代码中明确限制。
